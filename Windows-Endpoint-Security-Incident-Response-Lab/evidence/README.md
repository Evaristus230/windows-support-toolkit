# Evidence checklist

Add evidence only after personally completing the step in an authorized test environment. Keep raw output private; submit sanitized copies here only after checking for usernames, device names, email addresses, IP addresses, tenant names, file paths, and tokens.

- [ ] Baseline summary with collection date, Windows build, and environment noted.
- [ ] Defender and firewall status evidence, including any unavailable checks.
- [ ] Event summary evidence showing the channel, IDs, filter period, and result count.
- [ ] Completed fictional tabletop incident record.
- [ ] Evidence log showing source, collection time, handling notes, and redactions.
- [ ] Short reflection: what was verified, what was inferred, and what remains unknown.

No real endpoint evidence has been collected as part of creating this starter kit.
